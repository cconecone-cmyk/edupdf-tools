# 📚 EduPDF Tools - 教師備課與投影專用 PDF 工具箱

> **專為教育教學設計的純前端（Client-side）免伺服器 PDF 工具**  
> 專注於教學最核心的「**壓縮**」、「**拆分**」與「**合併**」，拒絕繁瑣設定，開啟即用、用了有感！

---

## 🌟 核心理念與特色

### 1. 🛡️ 100% 瀏覽器本地安全運算（零版權外洩風險）
* **免上傳伺服器**：一般線上壓縮工具（如 iLovePDF、Smallpdf）需要將檔案上傳到對方伺服器，可能存在書商教材版權與個資外流疑慮。
* **純前端處理**：本工具採用 `pdf-lib`、`pdf.js` 與 `JSZip`，完全使用使用者電腦的記憶體與運算資源，**檔案 0% 離開你的電腦**。

### 2. 🗜️ 智慧壓縮（教學投影優化 ＋ 最多 10 檔批次處理）
* **批次處理（最多 10 個檔案）**：支援一次拖入多個 PDF 檔案，清單一目了然，批次自動壓縮，並提供「📦 一鍵打包下載全部 (ZIP)」與個別單檔下載。
* **🎓 教室投影模式（150 DPI）**：
  * 大螢幕與黑板觸控屏專用，文字 100% 保持向量銳利，插圖放大 2 倍依然無鋸齒，體積瘦身 65%～75%。
* **📱 手機傳閱輕量模式（96 DPI）**：
  * 適合發送至 LINE 家長班群或 Google Classroom，極小體積、手機秒開。
* **⚙️ 抽屜式進階微調**：
  * 平常不干擾使用者；點開可切換「**灰階轉換**（黑白考卷體積再砍半）」或自訂解析度。
* **視覺化成果**：立即顯示「原大小 ➔ 瘦身後大小（節省了 XX%）」，一鍵下載。

### 3. ✂️ 單元拆分（課次分檔）
* **課次範圍拆分**：支援彈性語法，例如 `1-15:第一課, 16-30:第二課`，自動依名稱命名。
* **快捷按鈕**：一鍵快速填入「每 2 頁切一份」、「每 5 頁切一份」。
* **打包下載**：自動產出各單元獨立 PDF，並提供「📦 一鍵打包下載全部 (ZIP)」。

### 4. 📎 講義合併（含壓縮品質選擇）
* 拖入多份 PDF，提供 `↑` `↓` 自由調整先後順序。
* **合併後的壓縮品質直接三選一**：
  1. 💎 **保持原畫質**（不壓縮，1秒極速完成）
  2. 🎓 **教室投影優化**（合併後自動壓至 150 DPI）
  3. 📱 **手機傳閱輕量**（合併後深度壓至 96 DPI）

## 🚀 如何在 GitHub Pages 上線使用？

1. 在 GitHub 建立一個公開儲存庫（例如 `edupdf-tools`）。
2. 將本專案的 `index.html` 與 `README.md` 上傳至儲存庫。
3. 進入儲存庫的 **Settings** ➔ **Pages**。
4. 在 **Build and deployment** 下的 **Branch** 選擇 `main` 分支並按 **Save**。
5. 稍等約 1 分鐘，即可獲得公開專屬網址（例如：`https://<你的帳號>.github.io/edupdf-tools/`），全校老師均可免費、免安裝、免登入使用！
